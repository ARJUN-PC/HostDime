Kernel & GRUB:

1. Scenario: Your server suddenly fails to boot after a kernel update. How do you troubleshoot and recover the system?

Expected Answer: Boot into GRUB, select the previous working kernel, analyze /var/log/dmesg and journalctl -xb, check /boot/grub/grub.cfg, reinstall kernel if necessary.

2. Scenario: How would you modify the kernel parameters to optimize performance for a high-traffic web server?

Expected Answer: Modify /etc/sysctl.conf for parameters like vm.swappiness=10, fs.file-max=2097152, net.core.somaxconn=1024, apply changes with sysctl -p.

3. Scenario: Your server is running low on memory, and you suspect the kernel is overcommitting memory. How do you adjust it?

Expected Answer: Set vm.overcommit_memory=2 in /etc/sysctl.conf and adjust vm.overcommit_ratio

4. Scenario: You updated the kernel, but after a reboot, the server shows a kernel panic and won’t boot.

How do you recover the server?

Answer:

Boot into GRUB, select an older kernel.

Check logs with journalctl -xb.

Reinstall kernel: dnf reinstall kernel (RHEL) or apt install --reinstall linux-image-generic (Debian/Ubuntu).

If /boot is full, remove old kernels using dnf remove or apt autoremove.

5. Scenario: Your server has high I/O wait, and you want to tweak the I/O scheduler.

How do you change it persistently?

Answer:

Edit /etc/default/grub: GRUB_CMDLINE_LINUX="elevator=none"
Update grub: grub2-mkconfig -o /boot/grub2/grub.cfg
update-grub
Reboot the server.


Apache Performance Tuning:


6. Scenario: A website hosted on Apache is loading very slowly. How would you analyze and fix the issue?

Expected Answer: Check ab (Apache Bench), top, htop, iostat, vmstat, tweak MaxRequestWorkers, KeepAliveTimeout, enable caching via mod_cache, and optimize mpm_prefork or mpm_event.

Enable gzip compression

7. Scenario: Apache is crashing frequently under high load. What steps will you take?

Expected Answer: Check logs (/var/log/httpd/error_log), analyze ulimit -n, increase MaxClients, Timeout, use mpm_event instead of mpm_prefork.

8. Scenario: Apache is consuming too much CPU.

How do you diagnose and optimize?

Check load with top or htop.

Analyze slow logs: tail -f /var/log/httpd/error_log.

Optimize MPM module (mpm_event, mpm_prefork):
<IfModule mpm_event_module>
    StartServers 4
    MinSpareThreads 25
    MaxSpareThreads 75
    ThreadsPerChild 25
    MaxRequestWorkers 400
    MaxConnectionsPerChild 10000
</IfModule>

Enable caching (mod_cache, mod_expires).

9. Scenario: Apache is consuming excessive memory over time.

What do you do?

Use pmap <pid> to check memory usage.

Reduce MaxConnectionsPerChild in mpm_prefork.

Restart Apache periodically via cron.

**1. Linux Basics**

- **What are the differences between ext3 and ext4 filesystems?**
  - ext4 is an improvement over ext3 with features like journaling, larger file support, and faster performance.

- **How do you check disk usage and available space on a Linux server?**
  - Use `df -h` for disk usage and `du -sh /path/to/directory` for specific folder sizes.

- **Explain the purpose of /etc/fstab and how it is used.**
  - `/etc/fstab` defines filesystem mounts, automating mounting at boot.

- **What is the difference between cron and systemd timers?**
  - `cron` schedules jobs based on fixed time, while `systemd` timers provide more flexibility and integration.

- **How do you find and kill a running process by name?**
  - Use `ps aux | grep process_name` and `kill PID` or `pkill process_name`.

- **How do you manage file permissions and ownership in Linux?**
  - Use `chmod` for permissions and `chown` for ownership.

What is SNI?

SNI or server name induction is an extension of TLS protocol that allow the client to specify the hostname on TLS handshake.

What is MPM and type?

Multi processing module is used for handling the apache traffic. It is 3 types, prefork, worker and event
prefork - launch multiple child process, each process contain one connection at a time.
worker - launch multiple child process same as prefork but each child have multiple threads.
event - same as worker, used for heavy traffic

- **What is the difference between hard link and soft link?**
  - A hard link points to data directly; a soft link (symlink) points to another file.
A hardlink points the filename to data on a storage device but the softlink points the filename to another filename.

What is PHP -FPM
Fast process manager is used to minimize the memory consumption and increase the performance during the traffic.

What is the use of Virtualhost?
It allow one single machine to run multiple websites.

.htaccess --> The .htaccess file is a configuration file used on Apache web servers to set server configurations for a specific directory.

>>>>> This article covers how to change root mysql password in Windows/Plesk. <<<<<

Step 1.  Go to C:\Program Files\Parallels\Plesk\Databases\MySQL\Data\my.ini  and add the following line at the top:

skip-grant-tables

(this will let you access MySQL with no password)

Step 2.  Restart MySQL

Step 3.  Open CMD and change to the directory   C:\Program Files\Parallels\Plesk\Databases\MySQL\bin\

Step 4. Go into the MySQL command utility, (notice you are not using a password):

mysql -u root mysql

Step 5. Change the password using these two  commands

mysql>  UPDATE mysql.user SET Password=PASSWORD(‘New_Pass_Word’) WHERE User=’root’;

mysql>   FLUSH PRIVILEGES;

(New_Pass_Word  is the new password you would like to use )

(if the root user doesn’t work when updating the password in Plesk try changing the user from ‘root’ to ‘admin’ in the command above)

Step 6. Restart mysql

Step 7. Go into Plesk and update the MySQL password to the changed

Step 8. Remove the line ‘skip-grant-tables’ from the my.ini file and restart MySQL
