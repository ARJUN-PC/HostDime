Disk Partition and Mount
-------------------------

Tested in VMware - CentOS

1. Added a 20GB additional virtual drive
~~~

4. Select the storage disk for partitioning 
~~~
root@server:~# fdisk /dev/sdb

Welcome to fdisk (util-linux 2.40.2).
Changes will remain in memory only, until you decide to write them.
Be careful before using the write command.


Command (m for help): m
~~~

5. Now we are in fdisk, we can use `m` key for help, it will provide the details

6. Creating the new partition using the `n` key, Then give the partition type(primary or Extended), Then Partition number, Just press enter key in first sector and Enter the partition size in Last sector(+2GB). The partition is completed.
~~~
Command (m for help): n
Partition type
   p   primary (0 primary, 0 extended, 4 free)
   e   extended (container for logical partitions)
Select (default p): 

Using default response p.

First sector (2048-41943039, default 2048): 
Last sector, +/-sectors or +/-size{K,M,G,T,P} (2048-41943039, default 41943039): +2GB

Created a new partition 1 of type 'Linux' and of size 1.9 GiB.
~~~

Partition Completed and Now going for Mounting

1. Created the directory "/backup" for mounting
~~~
root@server:~# mkdir backup
~~~

2. Created file system (ext4)on the partition
~~~
root@server:~# mkfs -t ext4 /dev/sdb1
mke2fs 1.47.1 (20-May-2024)
Creating filesystem with 976562 4k blocks and 244320 inodes
Filesystem UUID: 4ed67adf-c924-4821-95b4-13157b033c61
Superblock backups stored on blocks: 
	32768, 98304, 163840, 229376, 294912, 819200, 884736

Allocating group tables: done                            
Writing inode tables: done                            
Creating journal (16384 blocks): done
Writing superblocks and filesystem accounting information: done
~~~

3. Need to add the entry in `/etc/fstab` for mounting the partition permanently, so before adding the partition we need UUID.
~~~
root@server:~# blkid /dev/sdb1
/dev/sdb1: UUID="4ed67adf-c924-4821-95b4-13157b033c61" BLOCK_SIZE="4096" TYPE="ext4" PARTUUID="26edad09-01"
~~~

4. Copied the UUID and add the details in fstab, (UUID, mount point, filesystem, frequency etc..)
~~~
UUID=4ed67adf-c924-4821-95b4-13157b033c61 /backup                 ext4    defaults        0 0
~~~

5. Mount the partition and performed a daemon-reload
~~~root@server:~# mount -a
mount: (hint) your fstab has been modified, but systemd still uses
       the old version; use 'systemctl daemon-reload' to reload.
root@server:~# 
root@server:~# 
root@server:~# systemctl daemon-reload
~~~
