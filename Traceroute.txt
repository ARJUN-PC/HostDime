How to perform trace-route from your system:

=============
If you have a system with WINDOWS OS : :
1. Click Start, then Run, type cmd and click OK.
2. Type pathping YOURDOMAIN.COM/IP and hit enter.
3. The protocol will generate a series of hops.
4. After the hops are generated, depending on the number of hops, it will say, "Analyzing for the next XXX seconds," where XXX refers to the number of seconds the analysis will take, usually over 100.
5. Please wait for the analysis to complete before pasting the results, as the analysis is the most important part of the pathping.
=============
If you have a system with MACINTOSH OS:
1. Open Finder, go to the Applications folder, then the Utilities Folder.
2. In the Utilities folder, launch the Terminal application.
3. Type traceroute -P icmp YOURDOMAIN.COM/IP and hit enter.
==============
If you have a system with LINUX OS:
1. Open Terminal from the PC.
2. Type traceroute YOURDOMAIN.COM/IP and hit enter.
