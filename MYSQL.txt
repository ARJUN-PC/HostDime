SQL Backup:
----------
		
mysqldump <database name> > <database_name>.sql
mysqldump -u username -p password <database name > > <database_name>.sql

SQL Restore:
------------
mysql <database name> < <database_name>.sql

Script to take all mysql backups:
=================================

mkdir /root/mysql-bak ; cd /root/mysql-bak
find /var/lib/mysql -maxdepth 1 -type d | awk -F\/ '{print $NF}' > db_name.list
for db in $(cat db_name.list) ; do echo "dumping $db" ; mysqldump $db > $db.sql ; done
                      or
mysql <database name> < /home/<database_name>.sql

Script for database restore:
----------------------------
for i in `cat /backup/db_list`; do mysql $i < /backup/mysql_backups/$i.sql; echo "$i" >> /backup/mysql_backups/Completed_dump.txt; done
